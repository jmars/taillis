# results/

The write-ups behind every number in this repository, and the analysis scripts that produced them.

**Raw run outputs are not published.** The `.txt`/`.json`/`.log` files these write-ups cite were
produced on one specific host, against model files that are not in this repository, and they are
mostly a record of that host's execution. What is kept is what a reader can check against the
argument: the write-up, and the script that derives the numbers.

Each write-up names the artifact it was measured on. Where a write-up cites an evidence file, that
file is on the author's machine, not here.
